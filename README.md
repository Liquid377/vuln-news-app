# Уведомления под себя: уязвимости и взломы — в Telegram

[![Канал](https://img.shields.io/badge/Telegram-канал%20@vuln__news__ru-26A5E4?logo=telegram)](https://t.me/vuln_news_ru)
[![Бот](https://img.shields.io/badge/Telegram-бот%20@vuln__news__ru__bot-26A5E4?logo=telegram)](https://t.me/vuln_news_ru_bot?start=github)

Это мини-приложение настроек бота **[@vuln_news_ru_bot](https://t.me/vuln_news_ru_bot?start=github)**: здесь вы выбираете продукты, а бот присылает уязвимости только по ним.

## Что вы получаете

- **CVE из NVD** с пометками: эксплуатируется ли в атаках (CISA KEV), вероятность эксплуатации (EPSS), есть ли публичный эксплойт или PoC, пишут ли о ней СМИ.
- **Взломы бирж, кошельков и протоколов**: все или по темам (TON, Россия и СНГ, биржи, кошельки, DeFi, мошенники).
- **БДУ ФСТЭК по российскому ПО**: Astra Linux, РЕД ОС, Альт, 1С, ViPNet, КриптоПро, Kaspersky, UserGate и другое — с версиями исправленных пакетов и мерами из БДУ.
- **Понятная карточка**: условия атаки простыми словами, версия с исправлением, ссылка на бюллетень и разбор в канале.
- **Без шума**: три уровня важности, выпуск Chrome на 20 CVE приходит одним сообщением, ночью — без звука. Если уязвимость позже начали эксплуатировать — придёт обновление.
- **Для команд**: бота можно добавить в рабочую группу, настройки в ней меняют только администраторы.

В каталоге около 180 продуктов: сетевое оборудование и периметр (Fortinet, Cisco, MikroTik, UserGate…), ОС и виртуализация, Microsoft, СУБД, CI/CD, почта и совместная работа, мониторинг (Zabbix, NetBox, Grafana…), ИИ-инструменты и российское ПО. Нет нужного — запросите прямо в приложении, добавим.

## Канал

**[@vuln_news_ru](https://t.me/vuln_news_ru)** — общая картина: важные уязвимости с разбором на русском, вечерний дайджест, изменения законодательства об ИБ и ПДн (152-ФЗ, 187-ФЗ, приказы ФСТЭК, ФСБ и Банка России), реестр сертифицированных СЗИ, утечки данных.

## Как начать

1. Откройте [@vuln_news_ru_bot](https://t.me/vuln_news_ru_bot?start=github) и нажмите «Запустить».
2. Нажмите «⚙️ Настройки» под полем ввода, отметьте своё ПО и уровень важности.
3. Всё. Дальше бот пишет сам — только по делу.

## Данные

Бот хранит только идентификатор чата, выбранные продукты и настройки. Имена, телефоны, названия компаний не хранятся; данные лежат на сервере в России. Команда `/delete` удаляет всё.
